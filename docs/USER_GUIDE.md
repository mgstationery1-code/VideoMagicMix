# VideoMagicMix v0.1.11 新手教程

## 一、先弄清 Hook、Body、字幕方案

- **Hook**：已经做好、带原声的开头视频，软件完整接在最前面，不给它另加配音或字幕。
- **Body**：开头后面的产品展示。从各组素材里选择完整视频、组合并变速，与对应配音长度对齐。
- **字幕方案**：一整套 Body 文案。一套文案配一条完整配音，但可以生成很多画面不同的视频。

成片顺序：`Hook → Body1 → Body2 → Body3……`。Body 视频原声关闭，使用上传的配音。

## 二、安装和启动

到 [最新正式版](https://github.com/mgstationery1-code/VideoMagicMix/releases/latest) 下载 Windows x64 包。

安装版：运行 `VideoMagicMix-Setup-0.1.11-x64.exe`，跟随向导安装。

目录版：下载 `VideoMagicMix-Windows-0.1.11-x64.zip`，完整解压再双击 `VideoMagicMix.exe`。不要在压缩包里面运行，不要只拖出 EXE。

无需安装 Python、Node.js、FFmpeg，识别模型已经包含。建议安装到短路径，例如 `D:\VideoMagicMix`，预留至少 10 GB 临时空间，批量输出另外预留空间。默认 CPU 识别，不强制显卡，电脑性能影响处理时间。

启动后等右上角连接成功。本地识别/渲染不依赖云端，下载更新需要联网。

## 三、准备和导入 Excel

保存为 `.xlsx`。新手建议只保留一个业务工作表，避免选错活动工作表。

| A：段落 | B：分组名称/相对路径 | C：方案1文案 | D：方案2文案 |
| --- | --- | --- | --- |
| Hook | 开头成片 | 可留空 | 可留空 |
| Body1 | 开头/刻字 | 这支铅笔可以刻名字，孩子一眼就能认出自己的。 | 名字刻在笔杆上，不容易拿错。 |
| Body2 | 加粗芯 | 加粗笔芯，日常写字更顺手。 | 加粗笔芯，写作业更安心。 |
| Body3 | 结尾展示 | 喜欢的朋友可以看一下。 | （此单元格实际留空） |

表格中“可留空”和括号说明不要照抄，它们只是解释。Hook 文案完全忽略；某方案的 Body 留空，代表该方案跳过这一段。A 列按 Body1、Body2……排列，可按实际需要安排 1–20 个 Body。分组名称要明确，避免重复。

C 列以后每个文案列是一套方案。**第一行必须有表头，例如 A1=段落、B1=分组、C1=字幕1、D1=字幕2；Hook 从第二行开始。** 每个方案表头必须填写，避免方案列未被识别。底部选择 Excel，再点“导入 Excel”。软件只读，不改写原文件；乱码、结构问题需要修正，空 Body 只是普通提示，不阻止流程。

## 四、选择素材目录

Hook 行点“浏览”，选完整开头目录。递归扫描根目录及子目录，每个有效视频是一个候选。Hook 必须有可读取的音轨；损坏或缺音轨会在预检指出。

Body 可以这样整理：

```text
D:\铅笔素材\
├─ 开头\刻字\
│  ├─ 刻字正面.mp4
│  └─ 刻字侧面.mp4
├─ 加粗芯\
│  ├─ 笔芯展示.mp4
│  └─ 写字展示.mp4
└─ 结尾展示\
   └─ 产品合照.mp4
```

点“选择并自动匹配”，选 `D:\铅笔素材`。B 列 `开头/刻字` 就会匹配 `D:\铅笔素材\开头\刻字`。

逐行确认目录正确。单组可以“添加/浏览”手动覆盖或“清除”。目录映射共享，方案切换时文案、时长和候选配置分别加载。空 Body 没有候选配置。

**输出目录不要放进素材目录树**，否则下次扫描可能把成片作为原始素材。

## 五、准备配音并识别

先在剪映等工具做好配音，支持 MP3、WAV、M4A、AAC、FLAC、OGG、OPUS。

一套方案上传一条完整音频，**只读有内容的 Body，按 Excel 顺序连续读，不读 Hook、Body 编号或分组名。**

上面方案1应读：

> 这支铅笔可以刻名字，孩子一眼就能认出自己的。加粗笔芯，日常写字更顺手。喜欢的朋友可以看一下。

在“字幕方案与配音”找到卡片，选择文件，点“上传与识别”。只上传一套方案的配音，也能生成多条成片。识别时看日志/任务；CPU 较慢或音频较长会更久，不要连续重复提交。

状态长时间不更新时，可点“重新识别并扫描”。失败先看 Body 行、Excel 文案、识别文字和时间。常见原因是读了 Hook、漏读/多读、音频属于另一套方案或录音背景音太强。修正文案/配音后重传识别，不要为通过随意确认错误时间。

成功后每组显示素材数、候选数、目标秒数；没有配音时长时还不能正确计算组合。

## 六、倍速和候选数量

倍速 = 组合素材原时长 ÷ 对应配音时长。

| 配音 | 组合素材 | 所需倍速 | 效果 |
| --- | --- | --- | --- |
| 10秒 | 12秒 | 1.2× | 加快到10秒 |
| 10秒 | 9秒 | 0.9× | 放慢到10秒 |
| 10秒 | 8秒+3秒 | 1.1× | 组合后加快到10秒 |

默认采用 0.9–1.4× 内的组合，每个 Body、每个方案独立设置。“候选数量”是组合数，不是文件数。修改数量自动调整范围；边界相同的组合可能一起进入，实际数可能多于目标。超出默认范围可能明显快慢，先看预览。

- **现有候选数量的预览**：看当前范围组合，例如 `刻字正面.mp4 + 刻字侧面.mp4`。
- **所有的组合预览**：看当前枚举范围内更广的组合，并非无限列出所有文件排列。
- **取消勾选**：不喜欢的组合不进最终混剪。
- **预渲染片段**：仅生成该 Body 已勾选组合的变速预览；完成后点组合播放。没点击就不提前渲染全部候选。

组合内不重复文件，不同成片间允许复用。同组 A+B 与 B+A 不会穷举为全部排列。每组最多选择距目标时长最近的18个素材参与枚举，每组合最多8段，最多70000候选。

## 七、BGM、音量和试听

BGM 行点“添加音频”选择音乐，不需要就清除。音乐只在 Body 开始播放，**Hook 没有 BGM**。

例：Body 配音30秒、音乐60秒，取前30秒；配音65秒、音乐30秒，循环两遍再接前5秒。

三个滑条分别控制配音、BGM、Hook，100%是原音量，0%静音，最高500%。建议从配音100–150%、BGM10–30%、Hook100%开始，再按实际录音调整。混音有峰值保护，但拉高并不保证听感好。

“试听文案”选择具体 Body，再点“试听所选片段”，听配音和 BGM 的比例；选 Hook 则试听第一个 Hook 原声，不混音乐。

## 八、字幕样式

默认只显示字体和字号，“更多字幕选项”可展开/收起粗体、颜色、描边、阴影、位置、边距、宽度和字幕字数阈值。

1080×1920 可先用字号52。想让不同电脑字幕一致，选内置 **Source Han Sans SC**。界面的 HarmonyOS 字体与成片字幕字体不是同一个设置。

字数阈值默认10，先按标点拆句，长句继续切短。例如“这学期开学，我把孩子的铅笔都换成了这款”，先按逗号分开，再拆较长部分；分隔标点不显示。

字幕按词级时间出现、切换，停顿可以没有字幕。选择 Body 预览段落，点小句看真实画面效果；样式变动会刷新，也可以点“刷新预览”。Hook 已有字幕，不在这里叠加。

## 九、生成数量、均衡轮换和复用

先试1–3条，再批量30或50条。

- **生成数量**：参与方案合计数量，不是每套各这么多。
- **关注最近**：每条与前几条比较 Body，推荐3。
- **Body复用目标**：推荐50%；留空只报告，不设目标。

软件优先少用近期出现过的素材、平衡累计曝光，尽量变化较长画面。Hook单独轮换，不靠只换开头掩盖重复后段。

例如两条 Body 都30秒，共用文件的画面时长12秒，复用率40%。同一文件换位置仍算共用；不同文件内容很像不会被视觉识别，所以这不是平台查重率。

关注最近3条：第5条与第2、3、4条比较；30条共84对，不等于全部435对都检查过。不同长度时按双方共用文件显示秒数的较小值求和，除以较短 Body 总时长。

点“预检并计算”，再看“查看选材与复用明细”：理论产能、本次安排、近期最高复用、超标的组、素材曝光。某个很长 Body 只有一个候选，会成为无法避免的重复；给这一组增加不同素材通常最有效。

**目标超标不会自动砍掉大量数量。** 可补素材、调整候选/目标后重检，或点“接受当前未达标安排”。接受表示同意当前显示结果，不代表已经达标。修改配置会使原确认失效。

理论组合不足仍无法凭空生成更多独立组合。每批最多安排5000条，0/留空按理论数量安排但也受此限制。算法有固定预算，不保证全局最优。

## 十、输出和任务

选择空间足够的输出目录。为了通用播放器兼容，新手推荐 **1080×1920、MP4、H.264、30fps、12或20Mbps、AAC192kbps**。软件原有默认是 MOV/HEVC，未改动；有些播放器没有 HEVC 解码器，打不开不一定损坏。

更高分辨率、帧率、码率通常占更多空间、耗时更长，不能把低清素材变成真正高清。

预检并确认后“开始渲染”，实际使用锁定安排；素材/音频/设置改变需要重检。

| 页签 | 内容 |
| --- | --- |
| 日志 | 导入、匹配、错误原因，在区域内滚动 |
| 任务 | 当前步骤、已完成/计划数量 |
| 产出 | 通过媒体检查的视频、实际数量、目录 |
| 去重变化 | 近期复用、选材、超标与曝光 |

“停止”取消后续工作，已完成文件保留。健康检查说明媒体可读及基础规格通过，不代替人工检查文案、画质和听感。

## 十一、常见问题

| 问题 | 处理 |
| --- | --- |
| Body没素材 | 核对B列路径、实际子文件夹、可读视频，确认没给每组错误指定总根目录 |
| 等待识别/扫描 | 看任务与日志，确认已上传；需要时点重新识别并扫描，避免连续重复提交 |
| 预检0条 | 日志看具体原因：音轨、目录、识别、倍速范围、全部取消勾选 |
| 字幕不对 | 确认配音对应方案且只读Body，核对识别与小句时间 |
| 听不到音乐 | 确认选了BGM且音量不为0；Hook无BGM是正常设计 |
| MOV/HEVC打不开 | 换支持HEVC的播放器，或选MP4/H.264重检渲染 |
| 换电脑字体不同 | 系统字体列表依电脑变化，字幕用内置思源 |
| 重启项目没了 | 本版项目在内存，重新导入；输出文件仍在原目录 |
| 更新失败 | 检查GitHub网络，也可手动下载正式包；本地混剪不受影响 |

水印、“智能压测”、“普通/分组”等历史占位按钮没有完整接入，不要依赖它们产生效果。教程只把实际可用流程写作功能。

## 十二、更新与数据

“检查更新”查询本仓库正式 Release，下载和退出安装会提示确认；识别/渲染期间阻止安装。目录版也可手动解压新版到新目录，安装版适合后续软件内更新。

v0.1.11 上传/缓存放在 `%APPDATA%\VideoMagicMix-balanced`，自选输出目录按你的设置。旧版目录不删除。保留原 Excel、配音和素材，以便重启后重新配置。
