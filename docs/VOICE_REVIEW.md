# 配音对齐与人工复核（v0.1.17）

软件使用 Excel 里的文案作为成片字幕，配音识别负责确定时间。识别成同音字时，不会把错字拿来做字幕。

## 自动处理

软件结合全文顺序、汉字和拼音匹配各个 Body。对部分常见口音提供近音容错，声调不同不会直接导致失败。部分疑难片段会使用现有本地模型再识别一次，仍不能可靠确认时交给你复核。

例如 Excel 是“工厂直销现货现发”，识别成“工厂持销线或线发”，新版可以结合拼音和上下文找到对应时间。不是所有不同读音都自动放行：真正漏读、多读或顺序错误仍可能需要处理。

## 人工复核怎么操作

1. 在“字幕方案与配音”上传该方案的完整 Body 配音，点击“上传并识别”。
2. 如果出现“待人工复核（N 段）”，点击旁边的“人工复核”。
3. 按 Body 编号和分组名找到问题段落。表格显示以下内容：

| 项目 | 示例 |
| --- | --- |
| Excel 文案 | 工厂直销现货现发 |
| 实际识别 | 工厂持销线或线发 |
| 识别时间 | 3.30–5.32 秒 |

4. 点击“试听此段”，听该时间范围内的原配音，不混入背景音乐。
5. 如果开始或结束位置不对，可以修改秒数，再试听。没有可靠定位的片段会标为“建议试听范围”。
6. 确认配音确实读了这段文案，且时间范围正确，点击“人工复核通过”。这个按钮只通过当前一段，不会通过其他待核对段落。
7. 全部通过后关闭复核窗口，继续设置素材、预检和渲染。人工复核后需要重新预检。

## 确认后会发生什么

- 字幕仍采用 Excel 文案，使用你确认的起止时间。
- 人工确认段落内部的小句按字数比例分配时间；这不等于恢复准确的逐字声学时间。如果切换仍不合适，应调整文案或配音后重新识别。
- 修改字幕样式不会清除确认。更换配音、重新识别或导入新项目不会沿用旧配音的确认记录。
- 不允许填写倒序、超出音频或与已确认前后段重叠的时间。
- 如果是识别引擎本身出错、没有产生识别结果，需要先处理错误，不能用复核按钮绕过。

这项功能帮助处理识别错字和部分口音，不保证任意口音都能自动准确对齐，也不会自动识别你是否真的听过配音。
