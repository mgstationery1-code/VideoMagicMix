# v0.1.11 · 均衡轮换版

本次发布用户确认的 v0.1.11 功能，不上传旧版安装包，不改变已有混剪、字幕、音频和布局规则。

## 新电脑安装

优先选择 Setup EXE；需要并排保留版本时选择完整 Windows ZIP。运行包包含模型、媒体工具、字体和独立后端，安装完成后无需再安装开发环境。仅支持 Windows x64。

[新手教程](USER_GUIDE.md) · [Codex 安装指引](../INSTALL_FOR_CODEX.md)

## 内容

- 素材曝光均衡轮换，优先改变长 Body 画面，Hook 独立轮换。
- 默认30条、关注前3条、Body复用目标50%；未达标明确提示并要求接受，不因目标直接缩减输出。
- 显示近期逐对比较、素材使用次数/秒数、无法避免的共用组和选材预览。
- 保留 Body 独立倍速/候选/取消勾选/预渲染、词级字幕、分段试听、Body-only BGM、输出检查和窗口拖动。
- 补齐 HarmonyOS 界面字体的离线嵌入及许可，避免依赖开发机字体安装。
- 完整目录包含逐文件校验清单；安装脚本先校验再解压，不覆盖已有目录。
- 文档已按均衡轮换规则更新，旧的整批硬上限说明只作历史参考。

## 边界

复用是原文件的画面时长复用，不是视觉相似度，也不保证整批任意两条达标；详细规则见教程。候选枚举及每批5000上限仍保留。项目状态仍在内存中；系统字幕字体列表依电脑变化，跨电脑一致请选内置字体。水印/智能压测等历史占位项未新实现。安装包未签名。

## 验收记录

原 v0.1.11 已通过74项 Python 测试、8项窗口测试、离线词级 ASR 和合成素材完整渲染/解码。正式发布资源补齐后的验证以 GitHub Actions 结果及 Release 中的验收说明为准；不把本机通过当作用户另一台电脑已经验收。
